# Tanisha Biswal — Portfolio

A neo-brutalist, retro-inspired portfolio built from scratch with plain HTML, CSS, and vanilla JavaScript. No frameworks, no shortcuts, just code.

## Why It Looks Like This

I wanted something that didn't blend in. So this one's loud on purpose: marquee tickers, floating stickers, an interactive timeline, and a blinking terminal prompt for good measure.

## Features

- Bold borders, hard shadows, colors that pop
- Light/dark theme toggle (remembers your choice)
- Fast-scrolling marquee tickers
- Interactive, color-coded timeline
- Zero dependencies, just clean frontend code

## Tech Stack

HTML5, CSS3 (custom properties, grid/flexbox, keyframe animations), and vanilla JavaScript (ES6). Fonts: Bebas Neue for headers, Space Mono for that terminal feel.
